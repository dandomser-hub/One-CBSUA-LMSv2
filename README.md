# One-CBSUA-LMSv2
For the Development to CI/CD of One-CBSUA LMSv2 (VLPv2)

## Project direction

One-CBSUA Learning Management System v2 (VLPv2) combines the relevant LMS2 functional baseline, selected Moodle-derived enhancements and CBSUA-specific requirements. It must operate independently while integrating with the University ERP: Registrar/SIS, HRMIS, FMIS and IAM/SSO.

The target serves Academic learners, Employee Learning and Development learners, and distant learners in university MOOC programs.

## Current status

Requirements documentation draft only. No application code, deployment or final stack is delivered by this change. The complete functional application, design/architecture artifacts, tests and operational materials are the repository's intended end state.
